# نظام العهد والمصروفات – مصنع السلامة

تطبيق Android لإدارة العهد المالية والمصروفات داخل مصنع السلامة.

## التقنيات
- Kotlin
- Jetpack Compose
- Firebase Authentication
- Cloud Firestore

## المستخدمون والصلاحيات

- عمرو سامي: مدير التطبيق وإدارة المستخدمين والإعدادات.
- عبدالله: موظف يسجل مصروفاته ومصروفات أحمد حسن.
- أحمد حمدي: يسجل مصروفاته فقط ويشاهد بياناته.
- سامي هنداوي: لوحة متابعة وتمويل وتسوية وإغلاق العهد.
- أحمد حسن: مستفيد مالي دون حساب دخول.

## المتطلبات الأساسية

- واجهة عربية RTL.
- حساب الرصيد من سجل الحركات المالية.
- تسجيل التمويل والمصروفات والتسويات.
- سجل تدقيق لكل العمليات.
- تقارير يومية وشهرية وسنوية.
- دعم العمل دون إنترنت والمزامنة.
- إشعارات للمستخدمين.
- عدم حذف القيود المالية نهائيًا.
- عدم إغلاق العهد تلقائيًا.

## الأمان

يجب فرض الصلاحيات من خلال قواعد قاعدة البيانات، وليس بمجرد إخفاء الأزرار داخل التطبيق.

لا ترفع مفاتيح Service Account أو كلمات المرور أو بيانات مالية حقيقية إلى المستودع العام.

## حالة المشروع

مرحلة التأسيس والتطوير. لم يتم اعتماد إصدار إنتاجي بعد.
