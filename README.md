# نظام العهد والمصروفات – مصنع السلامة

تطبيق Android عربي لإدارة العهد المالية والمصروفات داخل مصنع السلامة.

## التقنيات الحالية
- Kotlin
- Jetpack Compose

## تحديد واجهة الموظف
رمز الدخول وظيفته الوحيدة اختيار الموظف والواجهة والأقسام التي تظهر له. ليس المقصود به نظام حماية أو منع تطفل أو مصادقة أمنية.

- عمرو سامي: واجهة المدير وجميع الأقسام.
- عبدالله: واجهة مسؤول العمليات.
- أحمد حمدي: واجهة تسجيل مصروفاته الشخصية.
- سامي هنداوي: واجهة الإدارة المالية ومتابعة العهد.

## حالة النسخة الحالية
- شاشة إدخال الرمز.
- تحديد حساب الموظف محليًا حسب الرمز.
- عرض اسم الموظف ودوره والأقسام المخصصة له.
- الوظائف المالية الفعلية وقاعدة البيانات والمزامنة والإشعارات تُضاف في مراحل التطوير التالية.

## خفة التطبيق
لا تتم إضافة مكتبات أو خدمات إلا عند الحاجة الفعلية لاستخدامها. خدمات Firebase وقواعد البيانات والإشعارات ليست ضمن نسخة اختيار الواجهة الحالية، ويمكن إضافتها عند تنفيذ وظائفها.
